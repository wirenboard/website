#description

OpenTherm coupler WBE2-I-OPENTHERM is designed to work as an extension module for the WirenBoard 6…8 controllers, and is used for remote control of gas and electric boilers with OpenTherm interface.

Supported boilers with the protocol OpenTherm: Lemax, WARM, BAXI, Bosch, Buderus, DeDietrich, Ferroli, Fondital, Lamborghini, Novaflorida, Thermona, Viessmann etc


#info

## Technical Specifications

::product-section{title="Power Specifications"}
- nominal supply voltage: 5 V;
- maximum current consumption: 0.5 A.
::

::product-section{title="RS-485 / Modbus settings"}
- baud rate: 19200 bps;
- number of stop bits: 1;
- parity: none;
- data bits: 8;
- default device address: 11;
- optimal device polling interval: once per second.
::

::product-section{title="Other"}
- dimensions: 39x26x9 mm;
- weight: 30 g.
::

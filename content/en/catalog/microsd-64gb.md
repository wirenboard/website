::product
#description
An industrial 64 GB microSD memory card made by SCY (Shenzhen Shichuangyi Electronics) for controllers and other devices with a microSD slot.

#info
::product-section{title="Technical specifications"}
- Capacity: 64 GB.
- Read speed: up to 93 MB/s.
- Write speed: up to 88 MB/s.
- Operating temperature: from -25 to +85 °C.
- Storage temperature: from -40 to +85 °C.
::

::product-section{title="Other"}
- Manufacturer: SCY (Shenzhen Shichuangyi Electronics).
- Speed classes: Class 10, UHS Speed Class 3 (U3), Video Speed Class 30 (V30).
- Complies with SD specification version 6.1.
- Global wear leveling and ECC error correction.
::

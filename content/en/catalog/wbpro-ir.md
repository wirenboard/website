#description

Modbus IR remote control module. It can be used for remote control of climate control stations, fan coils, TV, lightening and other devices with IR-interface. Module has RS-485 interface for programming and control by PC or controller using Modbus RTU protocol.

Before using module must be teached using original remote control or IR commands can be programmed using RS-485 interface. It can store up to 32 IR commands.

Module has very small transmitter wich makes it almost invisible.Learning module with infrared transmitter. Controls air conditioning units, fan coils, TV sets etc. The module is managed by a controller or PC via RS-485 through Modbus RTU protocol commands.

You can create interactive graphic dashboards based on SVG drawings.

Information can be displayed in the text elements of the SVG drawing, and the visibility and design of the elements can be changed. You can also configure the reaction to a user action: turn on the light, turn off the alarm, etc.

The controller's web interface has a visual editor for setting up a graphic dashboard.

Read more about dashboards and other web interface features in the article [Wiren Board controller web interface](https://wirenboard.com/en/pages/wb-software/).

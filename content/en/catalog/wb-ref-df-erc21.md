#description

Network card for Danfoss refrigeration controller, which adds RS-485 interface with Modbus RTU protocol support. The device is connected to a Danfoss controller via a standard TTL connector. Flex cable included.

WB-REF-DF-ERC21 can be used in place of the original _Danfoss 191U0021_ NIC to connect a Danfoss temperature controller to a controller [Wiren Board](/product/wiren-board-6/).

Suitable for models:

- ERC 211
- ERC 213
- ERC 214

If you did not find your model in the list, see [other network cards](/catalog/ref-modbus-adapters/) for refrigeration. Perhaps your controller is supported by one of them.


::

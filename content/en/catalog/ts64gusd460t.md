#description

Transcend's microSDXC/SDHC 460T memory cards, using high-quality 3D NAND flash memory and rated for 3K P/E cycle times, combine the benefits of high performance and exceptional durability at an affordable price.


#info

## Technical Specifications

::product-section{title="Parameters"}
- capacity: 64 GB;
- write speed: up to 80 MB/s;
- read speed: up to 100 MB/s;
- MTBF: up to 3 million hours;
- operating temperature: from −25 to +85 °C;
- storage temperature: from −40 to +85 °C.
::

::product-section{title="Other"}
- manufacturer: Transcend;
- flash card type: microSDXC/TransFlash;
- card class: Class 10/UHS-I U1;
- chip type: 3D TLC NAND.

#description

The WBP-PASSIVE-POE power module is an embedded Passive PoE for [Wiren Board 7.4](/product/wiren-board-74/) and Wiren Board 8.4 controllers. Allows the controller to be powered from a passive splitter via a twisted-pair cable in an Ethernet network. If you need to connect the controller to a network with an active PoE switch, use [WBP-ACTIVE-POE](https://wirenboard.com/product/WBP-ACTIVE-POE/).

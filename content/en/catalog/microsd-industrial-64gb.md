#description

Transcend's microSDXC/SDHC 430T memory cards, using high-quality 3D NAND flash memory and rated for 3K P/E cycle times, combine the benefits of high performance and exceptional durability at an affordable price.


#info

## Technical specifications

::product-section{title="Parameters"}
- Capacity: 64 GB
- Write speed: up to 70 MB/s
- Read speed: up to 100 MB/s
- MTBF: up to 3 million hours
- Operating temperature, °C: from −25 °C to +85 °C
- Storage temperature, °C: from −40 °C to +85 °C
::

::product-section{title="Other"}
- Manufacturer: Transcend
- Card type: microSDXC/TransFlash
- Card class: Class 10/UHS-I U1
- Chip type: 3D TLC NAND

#description

Network card for Carel and Eliwell refrigeration controllers that adds an RS-485 interface with Modbus RTU protocol support. The device is connected to the refrigeration controllers via a standard connector. Cable for connection included.

WB-REF-U can be used to connect Carel and Eliwell controllers to [Wiren Board](/product/wiren-board-7/) controller, replacement card list:

- Carel - IROPZ48505 (IROPZ48500) and MCH2004850.
- Eliwell - DMI1001002000, DMI1002002000, DMI1003002000, SAR0RA00X701, BA11250N3700, BA00000XD000, BA00000XD002, BA00000XD001, BA10000R3700.

Compatible with controllers:

- Carel: BASIC, EASY, μRack, μC2SE, μC2, μGEO.
- Eliwell: ID 974 LX, ID 985 LX, ID PLUS 961, ID PLUS 974.

See the documentation for a complete list of models.

If you don't find your model in the list, check out [other network cards](/catalog/ref-modbus-adapters/) for refrigeration equipment. Perhaps your controller is supported by one of them.

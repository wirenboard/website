#description

**Outdated model, discontinued. Recommended [WB-MSW-LORA v.4](https://wirenboard.com/product/wb-msw4-lora/).**

Wireless hybrid digital sensor of temperature, humidity, illumination, noise, CO2 and VOC level. It is equipped with the IR blaster (and the receiver for learning). Designed for climate control in residential and office premises.

The sensor connects to the Wiren Board controller via LoRa or RS-485. The mode is selected by a switch on the board, in all cases the device needs external power. When using LoRa, you need to put a extension module in the controller [WBE2R-R-LORA](https://wirenboard.com/product/WBE2R-R-LORA/).


#info

## TECHNICAL SPECIFICATIONS

::product-section{title="MEASURED VALUES"}
- Temperature: -40°C — +80°C (±0.5°C)
- Humidity: 0 — 98% (±3%)
- Light: 0.02 — 100000 lux
- Noise level: 40 — 82 dB
- СО2 concentration: 0 — 5000 ppm.
- VOC concentration: 0 — 60000 ppb.
::

::product-section{title="ADDITIONAL FUNCTIONALITY"}
- IR commands sending
- Configurable buzzer(Mode on/off)
- Two-color indication, controlled via Modbus
- Heated sensor designed for operation in high humidity conditions
::

::product-section{title="OTHER CHARACTERISTICS"}
- Supply voltage: 9 — 28 VDC
- Interface: LoRa, RS-485 (Modbus RTU)
- Plastic enclosure with wall mounting option (83 x 83 x 21 mm)
::

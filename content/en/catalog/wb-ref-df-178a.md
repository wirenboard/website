#description

Network card for Danfoss refrigeration controller, which adds RS-485 interface with Modbus RTU protocol support. The device is installed in the controller case into a standard connector.

WB-REF-DF-178A can be used instead of original network card _ModBus EKA 178A (084B8564)_ to connect Danfoss temperature controller to controller [Wiren Board](/product/wiren-board-6).

Suitable for models:

- EKC 202D (084B8536)
- EKC 202B (084B8691)
- EKC 204A1 / AK-CC 210 (084B8520)

If you did not find your model in the list, see [other network cards](/catalog/ref-modbus-adapters/) for refrigeration. Perhaps your controller is supported by one of them.

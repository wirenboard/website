#description

The Z-Wave.Me Z-Stick 4 USB stick allows you to connect your Wiren Board controller to the Z-Wave network.

Included is the license for Z-Wave.Me Z-Way software stack for Z-Wave network.

Supports standard Zensys API (SerialAPI) and is compatible with commonly used software packages such as [HomeSeer](http://homeseer.com/), [Z-Command](http://www.z-command.com/), [mControl](http://www.embeddedautomation.com/), [Linux MCE](http://www.linuxmce.org/).


#info

## Technical specifications

::product-section{title="Options"}
- Radio protocol: Z-Wave
- Z-Wave chip generation: 5th
- Operating frequency: 869 MHz / 868.42 MHz. Switched programmatically.
- Number of supported network devices: 232
- USB Interface: 2.0

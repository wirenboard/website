#description

The WBE2R-R-ZWAVE-ZWAY module adds Z-Wave network support to the Wiren Board controller.

Included is the license for Z-Wave.Me Z-Way software stack for Z-Wave network.

Supports the standard Z-Wave Serial API and is compatible with [Z-Way](https://z-wave.me/z-way/), [Home Assistant](https://www.home-assistant.io/), [FHEM](https://fhem.de/), [Domoticz](https://domoticz.com/) and [OpenHAB](https://www.openhab.org/) programs.


#info

## Technical specifications

::product-section{title="Options"}
- Radio protocol: Z-Wave
- Z-Wave chip generation: 7th
- Operating frequency: 869 MHz / 868.42 MHz. Switched programmatically.
- Number of supported network devices: 232

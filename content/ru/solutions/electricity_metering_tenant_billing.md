## Задачи проекта

Необходимо было построить систему технического учета потребления электроэнергии арендаторами, и выставления им счетов за потребленную электроэнергию. Основной сложностью было то, что электрооборудование арендаторов было запитано множеством линий, и не было свободного места для установки такого количества электросчетчиков в существующих щитах. А реконструкцию электроустановки здания заказчик выполнять не планировал.

## Технические решения

### Архитектура системы

Проблема была решена при помощи многоканальных счетчиков [WB-MAP12E](https://wirenboard.com/ru/product/WB-MAP12E/): 12 измерительных каналов в корпусе шириной 106 мм позволили установить их прямо в существующих распределительных щитах, без отдельных шкафов учета и реконструкции электросети.

Для измерения тока установили разъемные трансформаторы, поэтому существующие кабели не пришлось перекоммутировать. Данные со счетчиков по Modbus RTU поступают на контроллер Wiren Board 8.5, установленный в отдельном щитке. Контроллер запитан по I категории от существующего АВР и подключен к локальной сети здания по Ethernet.

К этому же контроллеру по существующей линии RS-485 подключили счетчики «Меркурий» коммерческого учета. Ранее их показания передавал нестабильно работавший GSM-модуль, а после отказа от него данные снимали вручную.

Все задачи решили при помощи комплектного программного обеспечения контроллера Wiren Board и ПО Grafana, установленное на контроллере.

### Интерфейс пользователя

Для оперативной работы с системой использовали SVG-панели веб\-интерфейса контроллера. Они доступны как из локальной сети здания, так и удаленно, через Wiren Board Cloud.

Создали две панели:

- «АСКУЭ» — показывает текущее потребление электроэнергии по арендаторам и показания счетчиков «Меркурий».  
- «Счетчики» — используется для контроля и обслуживания WB-MAP. Счетчик можно выбрать по месту установки или адресу Modbus и посмотреть измеряемые параметры.

Для детального анализа данных использовали Grafana. В ней отображаются данные коммерческого учета по зданию и технического учета по арендаторам.

Для арендаторов доступны диаграммы полной, активной и реактивной мощности, потребление энергии за последние четыре месяца, текущие значения и графики изменения мощности и коэффициента мощности.

Для счетчиков «Меркурий» отображаются токи и напряжения по фазам, частота, активная мощность, показания счетчика и графики изменения параметров за выбранный период. Эти данные позволяют оценивать нагрузку линий и перекос по фазам.

В первый день каждого месяца система автоматически формирует отчет по потреблению электроэнергии арендаторами и отправляет его в специальный Telegram-канал для участников процесса биллинга.

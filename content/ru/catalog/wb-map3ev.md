#description

Трёхфазный вольтметр на DIN-рейку с интерфейсом RS-485.

Применяется для мониторинга качества электропитания, детектирования всплесков напряжения в одно- или трехфазных сетях переменного тока.


#info

## ОСНОВНЫЕ ХАРАКТЕРИСТИКИ

::product-section{title="Преимущества"}
:photo{
  src="wb-map3ev/wb-map3ev-1.png"
  width="500px"
  float="right"
}

- измерение трехфазного напряжения;
- детектирование всплесков напряжения;
- измерение пиковых значений напряжений и межфазных углов;
- компактный корпус на DIN-рейку;
- срок службы 16 лет;
- быстрая и простая интеграция в систему автоматизации и мониторинга;

- техническая поддержка на портале;
- русскоязычная документация;
- возможно нанесение логотипа вашей компании.

Поддерживает [Быстрый Modbus](https://wirenboard.com/wiki/Fast_Modbus) ⚡, что позволяет мгновенно доставлять значение действующего напряжения в контроллер Wiren Board.
::

::product-section{title="Аппаратная часть"}
:photo{
  src="wb-map3ev/wb-map3ev-2.png"
  width="500px"
  float="right"
}

Измеряемые параметры:

- среднеквадратическое значение фазного напряжения (Urms);
- фазовый угол сдвига напряжения между фазами;
- частота;

- напряжение питания: 9…28 В постоянного тока;
- интерфейс: RS-485, Modbus RTU;
- расширенный диапазон температуры эксплуатации: -40…+80 °С;
- корпус на DIN-рейку, 2 модуля.
::

::product-section{title="Мониторинг электросетей"}
:photo{
  src="wb-map3ev/wb-map3ev-3.png"
  width="500px"
  float="right"
}

WB-MAP3EV используется в системах мониторинга электросетей на промышленных предприятиях, офисных зданиях, дата-центрах.

Измеренные параметры могут быть использованы для контроля фазного напряжения. А также выявления аварийных ситуаций:

- отсутствия фаз;
- неравномерности напряжения фаз;
- дисбаланса фазного угла;
- перепадов напряжения.

Для передачи значений действующего напряжения (Urms) WB-MAP3EV использует Быстрый Modbus ⚡. Это позволяет мгновенно обнаруживать отклонение фазного напряжения от нормы и своевременно принимать меры для защиты электрооборудования.
::

::product-section{title="Поддержка Быстрого Modbus"}
:photo{
  src="wb-map3ev/wb-map3ev-4.png"
  width="500px"
  float="right"
}

Все устройства Wiren Board в дополнение к стандартному Modbus RTU могут работать с его расширением [Быстрый Modbus](https://wirenboard.com/wiki/Fast_Modbus) ⚡, которое добавляет новые возможности:

- мгновенный опрос состояний входов и измеренных значений через события;
- быстрый поиск подключённых к контроллеру устройств;
- разрешение коллизий адресов на шине.

Для пользователя включение дополнительных возможностей происходит незаметно — если устройство поддерживает расширение, драйвер контроллера будет работать с устройством по Быстрому Modbus, если устройство ничего про расширение не знает — оно будет работать по стандартному Modbus RTU.
::

::product-section{title="Настройка"}
:photo{
  src="wb-map3ev/wb-map3ev-5.png"
  width="500px"
  float="right"
}

При использовании с контроллером Wiren Board вы можете мышкой в веб-интерфейсе:

- настраивать период сброса пиковых значений;
- включать и отключать опрос параметров.

Для настройки без контроллера можно использовать [Веб-конфигуратор устройств Wiren Board](https://wiki.wirenboard.com/wiki/WASM_Device_Editor) с преобразователем интерфейсов WB-USB485 или другим.

При использовании с другим оборудованием модуль можно настраивать по шине RS-485 через запись значений в Modbus-регистры. Таблица регистров открыта, хорошо документирована и доступна онлайн в документации на устройство.
::

::product-section{title="Чтение показаний"}
:photo{
  src="wb-map3ev/wb-map3ev-6.png"
  width="500px"
  float="right"
}

У вольтметра нет собственного экрана, поэтому считывание измеренных параметров производится по интерфейсу RS-485, Modbus RTU.

Если используется контроллер Wiren Board, то значения измеренных величин доступны в веб-интерфейсе контроллера и могут быть переданы в систему верхнего уровня. В карточке устройства отображаются только включенные в настройках опроса каналы.

Все данные можно читать любым оборудованием или ПО с поддержкой протокола RS-485, Modbus RTU: контроллерами сторонних производителей, HMI панелями или SCADA.
::

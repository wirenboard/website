#description

**Модель снята с производства. Рекомендуемая замена: [WB-MSW-ZIGBEE v.4](https://wirenboard.com/product/wb-msw4-zigbee/).**

Применяется для измерения параметров климата в условиях сложной радиообстановки, например, подвалах с толстыми стенами, удалённых складских помещениях и бытовках, помещениях на разных этажах здания.

Подключается к контроллеру Wiren Board через LoRa (нужно установить адаптер [WBE2R-R-LORA](https://wirenboard.com/product/WBE2R-R-LORA/)) или RS-485.

- 8 измеряемых параметров в одном корпусе.

- Возможно нанесение логотипа вашей компании.

Поддерживает [Быстрый Modbus](https://wirenboard.com/wiki/Fast_Modbus) ⚡ при работе через RS-485, что позволяет мгновенно доставлять события датчика движения в контроллер Wiren Board.

Измеряемые параметры:

- Температура: -40°С…+80°С (±0.5°С).
- Влажность: 0…95% (±3%).
- Освещенность: 0.02…145000 лк.
- Уровень шума: 39…90 дБА.
- Концентрация СО2: 400…10000 ppm.
- Концентрация VOC: 0…60000 ppb.
- Движение: до 8 м, угол до 120°.
- Передача ИК-команд: до 10 м.
- Управляемый зуммер.
- Двухцветная индикация, управляемая по Modbus.
- Подогрев датчика для работы в условиях высокой влажности.

- Напряжение питания: 9...28 В постоянного тока.
- Потребляемая мощность: 0,5...4 Вт.
- Интерфейс: RS-485, Modbus RTU.
- Пластиковый корпус с возможностью крепления на подрозетник (80x80x19 мм).
::

::product-section{title="Технология LoRa"}
:photo{
  src="wb-msw4-lora/wb-msw4-lora-3.jpeg"
  width="500px"
  float="right"
}

Для передачи данных используется технология беспроводной передачи данных LoRa с частотой 869.125 МГц, что обеспечивает дальность до 1.5 км на открытой местности, а также высокую проникающую способность сигнала через преграды.

Благодаря высокой проникающей способности сигнала датчик может быть установлен в сложных условиях:

- подвалы с толстыми стенами;
- удалённые складские помещения и бытовки;
- помещения на разных этажах здания.

Скорость передачи данных в сети LoRa составляет 2,4 кбит/с, а типичное время передачи одного пакета Modbus — примерно 0,3 с. Этого вполне достаточно для задач контроля климата.
::

::product-section{title="Управление ИК-командами"}
:photo{
  src="wb-msw4-lora/wb-msw4-lora-4.jpeg"
  width="500px"
  float="right"
}

WB-MSW-LORA v.4 есть инфракрасный приёмопередатчик для записи сигналов с ИК-пультов ДУ бытовых устройств и дальнейшего управления бытовой техникой: кондиционерами, телевизорами, тепловыми завесами и т.д.

В энергонезависимой памяти датчика может храниться до 80 ИК-команд. Запись команд выполняется с помощью ДУ пульта оборудования.

Подробно работа с ИК-командами описана в документации.
::

::product-section{title="Контроль уровня CO2"}
:photo{
  src="wb-msw4-lora/wb-msw4-lora-5.jpg"
  width="500px"
  float="right"
}

CO2 (углекислый газ) - газ без цвета с легким кислым запахом, тяжелее воздуха. Всегда присутствует в воздухе и в небольших количествах для человека безвреден. CO2 не поддерживает дыхание, поэтому при больших концентрациях негативно влияет на состояние человека и может привести к смерти от удушья.

В WB-MSW-LORA v.4 для измерения концентрации CO2 используется недисперсионный инфракрасный (NDIR) сенсор. Он позволяет проводить измерения с погрешностью 100 ppm + 5% от измеренного значения.
::

::product-section{title="Контроль VOC"}
:photo{
  src="wb-msw4-lora/wb-msw4-lora-6.jpg"
  width="500px"
  float="right"
}

Летучие органические вещества (ЛОВ, VOC) — это вещества, выделяющиеся в атмосферу в виде газов: испарения лаков/красок и элементов внутренней отделки помещений (фенол, формальдегид, толуол, стирол), спирты, бензол, гниющие овощи, выделяемые человеком газы, бытовой газ. Высокие концентрации опасных ЛОВ представляют угрозу жизни и здоровью человека.

Датчик VOC определяет суммарную концентрацию этих веществ c типовой погрешностью ±15 %.
::

::product-section{title="Настройка"}
:photo{
  src="wb-msw4-lora/wb-msw4-lora-7.png"
  width="500px"
  float="right"
}

При подключении датчика к контроллеру Wiren Board по RS-485 вы можете мышкой в веб-интерфейсе:

- настроить автокалибровку датчика CO2 и компенсацию самонагрева,
- настроить время усреднения шума и движения,
- включать и отключать опрос параметров.

При использовании с другим оборудованием датчик можно настраивать по шине RS-485 через запись значений в Modbus-регистры. Таблица регистров открыта, хорошо документирована и доступна на нашем сайте.
::

  src="wb-msw4-lora/wb-msw4-lora-8.png"

Если используется контроллер Wiren Board, то измеренные значения доступны в веб-интерфейсе контроллера и могут быть использованы в сценариях автоматизации или переданы в систему верхнего уровня.

Также датчик может передавать данные по Modbus RTU (RS-485), которые можно читать любым оборудованием или ПО с поддержкой этого протокола: контроллерами сторонних производителей, HMI панелями или SCADA.

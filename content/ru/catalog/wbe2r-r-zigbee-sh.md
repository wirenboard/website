#description

Лицензия на ПО Sprut.hub и модуль для подключения Zigbee-устройств. Работает только с ПО Sprut.hub для домашней автоматизации, [подробнее в документации](https://wirenboard.com/wiki/SprutHub).

Устанавливается в разъём на плате контроллера, подходит для Wiren Board 6…8. В комплекте идет [антенна](https://wirenboard.com/ru/product/wi-fi-2dbi-antenna/), её подключение производится через разъём SMA male.

Важно! Этот модуль не работает с zigbee2mqtt, используйте [WBE2R-R-ZIGBEE v.2](/product/WBE2R-R-ZIGBEE-v2/).

#description

Универсальный измеритель параметров электрических сетей с 4 трехфазными или 12 однофазными измерительными каналами и интерфейсом RS-485. Используется с разъемными трансформаторами тока.

Применяется для измерения всех видов электрических параметров в трехфазных и однофазных сетях переменного тока, для организации системы технического учета электроэнергии.

Является средством измерений. Номер в реестре СИ: [79082-20](https://fgis.gost.ru/fundmetrology/cm/mits/671d33e1-6c8d-88d6-f588-c9c7403f826a).

WB-MAP12E включен в [реестр](https://gisp.gov.ru/goods/#/product/5964730) Минпромторга.

## Примеры использования

::product-section{title="Преимущества"}
:photo{
  src="wb-map12e/wb-map12e-1.png"
  width="500px"
  float="right"
}

- является средством измерений, подходит для технического учета;
- низкая стоимость измерительного канала;
- хранит накопленные показания при отключении питания;
- использование внешних разъемных трансформаторов тока позволяет производить монтаж системы без отключения потребителей;
- большое количество измеряемых параметров;
- настраиваемый маппинг фаз упрощает монтаж и пусконаладку;
- срок службы 16 лет;
- быстрая и простая интеграция в систему автоматизации и мониторинга;

- техническая поддержка на портале;
- русскоязычная документация;
- возможно нанесение логотипа вашей компании.

Поддерживает [Быстрый Modbus](https://wirenboard.com/wiki/Fast_Modbus) ⚡, что позволяет мгновенно доставлять значение действующего напряжения в контроллер Wiren Board.
::

::product-section{title="Аппаратная часть"}
:photo{
  src="wb-map12e/wb-map12e-2.png"
  width="500px"
  float="right"
}

Измеряемые параметры:

- среднеквадратичные значения тока и напряжения (Urms);
- мощность (активная, реактивная, полная, кажущаяся) и коэффициент мощности;
- энергия прямая и обратная (активная, реактивная, кажущаяся, неактивная);
- суммарные значения мощностей и энергий при подключении трехфазных нагрузок;
- амплитуда всплесков напряжения и тока. Ширина измеряемых пиков — от 300 мкс, определяется фильтрами на входах, значения пиков обновляются периодически, период настраивается (минута по умолчанию);
- углы фазовых сдвигов, частота;

- класс точности 0.5S для активных мощности и энергии и 1 для реактивных мощности и энергии;
- напряжение питания: 9…28 В постоянного тока и 230 В переменного тока;
- интерфейс: RS-485, Modbus RTU;
- расширенный диапазон температуры эксплуатации: -40…+80 °С;
- корпус на DIN-рейку, 6М (108 x 90 x 58 мм).
::

::product-section{title="Монтаж без вмешательства в систему электроснабжения"}
:photo{
  src="wb-map12e/wb-map12e-3.png"
  width="500px"
  float="right"
}

Счетчик может быть подключен к существующей системе электроснабжения без вмешательства в электропроводку и необходимости отключения силовых проводов от автоматических выключателей. Для этого вместе со счетчиком используются токовые трансформаторы с разъемным сердечником. Все что нужно сделать при монтаже — подключить фазные линии к клеммам счетчика и надеть токовые трансформаторы на силовые провода.

Счетчик устанавливается на DIN-рейку в распределительный щит или внутри корпуса электрооборудования.
::

::product-section{title="Мониторинг электросети"}
:photo{
  src="wb-map12e/wb-map12e-4.png"
  width="500px"
  float="right"
}

WB-MAP12E используется в системах [мониторинга электросетей](https://wirenboard.com/ru/pages/enegro_monitoring/) на промышленных предприятиях, офисных зданиях, дата-центрах. Измеряет все основные параметры электросети, заменяя собой несколько измерительных приборов: вольтметр, амперметр, ваттметр, частотомер.

Измеренные параметры могут быть использованы для контроля потребления и качества электроэнергии. А также выявления аварийных ситуаций:

- отсутствия фаз;
- неравномерности напряжения фаз;
- дисбаланса фазного угла;
- перепадов напряжения.

Для передачи значений действующего напряжения (Urms) WB-MAP12E использует Быстрый Modbus ⚡. Это позволяет мгновенно обнаруживать отклонение фазного напряжения от нормы и своевременно принимать меры для защиты электрооборудования.
::

::product-section{title="Управление приоритетами нагрузок"}
:photo{
  src="wb-map12e/wb-map12e-5.png"
  width="500px"
  float="right"
}

Измеренные параметры удобно использовать в задачах управления приоритетами нагрузок для контроля потребления на каждой линии. WB-MAP12E может непрерывно измерять ток на 4 трехфазных или 12 однофазных каналах и передавать показания в контроллер. В случае превышения допустимого тока потребления, отключается нагрузка с низким приоритетом. Для отключения нагрузок можно использовать [модули реле Wiren Board](https://wirenboard.com/ru/catalog/wb-mr-relay-modules/).

Если не нужно измерять напряжение и энергию, то для измерения тока счетчик не обязательно подключать к силовым линиям, достаточно надеть токовый трансформатор с разъемным сердечником на измеряемую линию. Это позволяет упростить монтаж и интеграцию в систему автоматизации.
::

::product-section{title="Настройка"}
:photo{
  src="wb-map12e/wb-map12e-7.png"
  width="500px"
  float="right"
}

При использовании с контроллером Wiren Board вы можете мышкой в веб-интерфейсе:

- вносить калибровочные параметры трансформаторов тока;
- настраивать маппинг фаз;
- настраивать период сброса пиковых значений;
- включать и отключать опрос параметров;
- задавать скорость обмена данными.

Для настройки без контроллера можно использовать [Веб-конфигуратор устройств Wiren Board](https://wiki.wirenboard.com/wiki/WASM_Device_Editor) с преобразователем интерфейсов WB-USB485 или другим.

При использовании с другим оборудованием модуль можно настраивать по шине RS-485 через запись значений в Modbus-регистры. Таблица регистров открыта, хорошо документирована и доступна онлайн в документации на устройство.
::

::product-section{title="Чтение показаний"}
:photo{
  src="wb-map12e/wb-map12e-8.png"
  width="500px"
  float="right"
}

У счетчика нет собственного экрана, поэтому считывание измеренных параметров производится по интерфейсу RS-485, Modbus RTU.

Если используется контроллер Wiren Board, то значения измеренных величин доступны в веб-интерфейсе контроллера и могут быть переданы в систему верхнего уровня. В карточке устройства отображаются только включенные в настройках опроса каналы.

Все данные можно читать любым оборудованием или ПО с поддержкой протокола RS-485, Modbus RTU: контроллерами сторонних производителей, HMI панелями или SCADA.
::

#description

Трехканальный диммер с интерфейсом RS-485. Монтируется на DIN-рейку, имеет 6 входов для управления выходами. Позволяет реализовать управление диммируемым освещением с помощью кнопочных выключателей.

Применяется для диммирования ламп накаливания, а также поддерживающих функцию диммирования светодиодных ламп, драйверов светодиодных лент, электронных трансформаторов питания галогенных ламп и т.п.

Модуль WB-MDM3 включен в реестр Минпромторга.

## ОСНОВНЫЕ ХАРАКТЕРИСТИКИ

::product-section{title="Преимущества"}
:photo{
  src="wb-mdm3/wb-mdm3-1.png"
  width="500px"
  float="right"
}

- мощность до 300 Вт на канал;
- гибкая настройка управления кнопками и распознавание нажатий, позволяет настраивать управление выходами со входов;
- выбор режима управления: по заднему и по переднему фронту, для разных типов нагрузок;
- независимое управление каждым каналом;
- плавное изменение яркости и настройка скорости изменения яркости;
- ключевой режим, для управления вместо реле, но без щелчков;
- индикация состояния каналов и срабатывания защиты для диагностики;
- можно использовать для регулировки оборотов вентиляторов мощностью до 30 Вт;
- компактный корпус на DIN-рейку;
- быстрая и простая интеграция в систему автоматизации и мониторинга;

- техническая поддержка на портале;
- русскоязычная документация;
- возможно нанесение логотипа вашей компании.

Поддерживает [Быстрый Modbus](https://wirenboard.com/wiki/Fast_Modbus) ⚡, что позволяет мгновенно доставлять состояния входов и значения счетчиков нажатий в контроллер Wiren Board.
::

::product-section{title="Аппаратная часть"}
:photo{
  src="wb-mdm3/wb-mdm3-2.png"
  width="500px"

}

Технические характеристики:

- 3 канала диммирования мощностью до 300 Вт на канал;
- 6 дискретных входов;
- отсечка фазы по переднему фронту или по заднему фронту;
- шаг диммирования — 1 %;
- защита от КЗ, перегрева и противопожарная;
- групповая гальваническая изоляция входов;
- входы типа «сухой контакт»;

- напряжение питания: 9…28 В постоянного тока;
- интерфейс: RS-485, Modbus RTU;
- расширенный диапазон температуры эксплуатации: -40…+80 °С;
- корпус на DIN-рейку, 3M (53 x 90 x 58 мм).
::

::product-section{title="Локальное управление"}
:photo{
  src="wb-mdm3/wb-mdm3-3.jpg"
  width="500px"
  float="right"
}

Гибкая настройка реакции выходов на нажатия кнопок позволяет использовать модуль для локального управления освещением без контроллера. Это удобно в небольших инсталляциях, где нет возможности проложить шину RS-485.

Если модуль подключен к шине, то локальную логику можно комбинировать с командами от контроллера. Взаимодействие входов и выходов настраивается в веб-интерфейсе контроллера Wiren Board или записью в Modbus-регистры, а настройки хранятся в памяти модуля.
::

::product-section{title="Диммирование по переднему и заднему фронту"}
:photo{
  src="wb-mdm3/wb-mdm3-4.png"
  width="500px"
  float="right"
}

Для каждого канала можно настроить один из двух режимов диммирования: по переднему или по заднему фронту.

Режим по переднему фронту используется для диммирования индуктивных нагрузок: вентиляторы, электродвигатели. По заднему фронту — для диммирования светодиодных ламп и диммируемых драйверов светодиодных ламп.

Для отсечки фазы используются MOSFET-транзисторы, которые обеспечивают низкий нагрев и более высокое быстродействие по сравнению с симисторами (TRIAC).
::

::product-section{title="Поддержка Быстрого Modbus"}
:photo{
  src="wb-mdm3/wb-mdm3-5.png"
  width="500px"
  float="right"
}

Все устройства Wiren Board в дополнение к стандартному Modbus RTU могут работать с его расширением [Быстрый Modbus](https://wirenboard.com/wiki/Fast_Modbus) ⚡, которое добавляет новые возможности:

- мгновенный опрос состояний входов и измеренных значений через события;
- быстрый поиск подключённых к контроллеру устройств;
- разрешение коллизий адресов на шине.

Для пользователя включение дополнительных возможностей происходит незаметно — если устройство поддерживает расширение, драйвер контроллера будет работать с устройством по Быстрому Modbus, если устройство ничего про расширение не знает — оно будет работать по стандартному Modbus RTU.
::

::product-section{title="Настройка"}
:photo{
  src="wb-mdm3/wb-mdm3-6.png"
  width="500px"
  float="right"
}

При использовании с контроллером Wiren Board вы можете мышкой в веб-интерфейсе:

- переключать тип диммирования: по переднему или по заднему фронту;
- задавать минимальные и максимальные диапазоны диммирования;
- настраивать скорость диммирования;
- настраивать обработку нажатий кнопок на входах и взаимодействие входов с выходами;
- включать и отключать опрос параметров.

Для настройки без контроллера можно использовать [Веб-конфигуратор устройств Wiren Board](https://wiki.wirenboard.com/wiki/WASM_Device_Editor) с преобразователем интерфейсов WB-USB485 или другим.

При использовании с другим оборудованием модуль можно настраивать по шине RS-485 через запись значений в Modbus-регистры. Таблица регистров открыта, хорошо документирована и доступна онлайн в документации на устройство.
::

::product-section{title="Чтение показаний"}
:photo{
  src="wb-mdm3/wb-mdm3-7.png"
  width="500px"
  float="right"
}

Если используется контроллер Wiren Board, то функции управления каналами, состояния входов и счетчики нажатий доступны в веб-интерфейсе контроллера и могут быть использованы в сценариях автоматизации или переданы в систему верхнего уровня. В карточке устройства отображаются только включенные в настройках опроса каналы.

Все данные можно читать любым оборудованием или ПО с поддержкой протокола RS-485, Modbus RTU: контроллерами сторонних производителей, HMI панелями или SCADA.

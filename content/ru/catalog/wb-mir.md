#description

Обучаемый модуль с выносным инфракрасным передатчиком и интерфейсом RS-485. ИК-команды программируются с помощью пульта дистанционного управления от бытовой техники или по интерфейсу RS-485.

Применяется в системах автоматизации для управления кондиционерами, фанкойлами, тепловыми завесами, телевизорами и т.п. Устанавливается в корпус управляемого устройства.


#info

## Основные характеристики

::product-section{title="Преимущества"}
:photo{
  src="wb-mir/wb-mir-advantages.png"
  width="500px"
  float="right"
}

- компактный корпус, можно установить в корпусе устройства;
- в памяти модуля хранится до 80 команд;
- обучается с пульта управления, поэтому не нужно искать команды в базах;
- есть вход 1-Wire для подключения до 20 датчиков температуры DS18B20, который можно использовать как вход «сухой контакт»;
- поддерживает Быстрый Modbus;
- внешний ИК-передатчик в комплекте;

- техническая поддержка на портале;
- русскоязычная документация;
- возможно нанесение логотипа вашей компании.

Поддерживает [Быстрый Modbus](https://wirenboard.com/wiki/Fast_Modbus) ⚡, что позволяет мгновенно доставлять состояния входов и значения счетчиков нажатий в контроллер Wiren Board.

::product-section{title="Управление ИК-командами без дополнительных устройств"}
:photo{
  src="wb-mir/wb-mir-ir-commands.jpg"
  width="500px"
  float="right"
}

WB-MIR позволяет записывать сигналы с ИК-пультов ДУ бытовых устройств для дальнейшего управления бытовой техникой: кондиционерами, телевизорами, тепловыми завесами и т.д. При этом модуль устанавливается скрыто внутри корпуса управляемого устройства, не портит интерьер и не занимает место.

В энергонезависимой памяти модуля может храниться до 80 ИК-команд, которые записываются с помощью ДУ пульта оборудования. Подробно работа с ИК-командами описана в документации.
::

::product-section{title="Универсальное решение для управления климатом"}
:photo{
  src="wb-mir/wb-mir-climate.jpg"
  width="500px"
  float="right"
}

Подключив к модулю WB-MIR внешние датчики температуры 1-Wire, можно реализовать точное управление климатическим оборудованием, например, кондиционером. Внешние датчики можно установить там, где они будут давать более правдивые показания, а логику работы запрограммировать в веб-интерфейсе контроллера Wiren Board.

Встроенный в контроллер движок правил wb-rules позволяет реализовать алгоритмы регулирования, более точные, чем те, которые заложены в климатические устройства по умолчанию. Благодаря этому можно повысить качество управления микроклиматом в помещении.
::

::product-section{title="Поддержка Быстрого Modbus"}
:photo{
  src="wb-mir/wb-mir-fast-modbus-support.png"
  width="500px"
  float="right"
}

Все устройства Wiren Board в дополнение к стандартному Modbus RTU могут работать с его расширением [Быстрый Modbus](https://wirenboard.com/wiki/Fast_Modbus) ⚡, которое добавляет новые возможности:

- мгновенный опрос состояний входов и измеренных значений через события;
- быстрый поиск подключённых к контроллеру устройств;
- разрешение коллизий адресов на шине.

Для пользователя включение дополнительных возможностей происходит незаметно — если устройство поддерживает расширение, драйвер контроллера будет работать с устройством по Быстрому Modbus, если устройство ничего про расширение не знает — оно будет работать по стандартному Modbus RTU.
::

::product-section{title="Настройка"}
:photo{
  src="wb-mir/wb-mir-setup.png"
  width="500px"
  float="right"
}

При использовании с контроллером Wiren Board вы можете мышкой в веб-интерфейсе:

- включать и отключать каналы и настраивать период опроса;
- управлять режимом записи команд с пульта ДУ;
- воспроизводить ИК-команды;
- переключать режим работы входа.

Для настройки без контроллера можно использовать [Веб-конфигуратор устройств Wiren Board](https://wiki.wirenboard.com/wiki/WASM_Device_Editor) с преобразователем интерфейсов WB-USB485 или другим.

При использовании с другим оборудованием модуль можно настраивать по шине RS-485 через запись значений в Modbus-регистры. Таблица регистров открыта, хорошо документирована и доступна онлайн в документации на устройство.
::

::product-section{title="Чтение показаний"}
:photo{
  src="wb-mir/wb-mir-readings.png"
  width="500px"
  float="right"
}

Если используется контроллер Wiren Board, то показания датчиков температуры и состояние входа доступны в веб-интерфейсе контроллера и могут быть использованы в сценариях автоматизации или переданы в систему верхнего уровня. В карточке устройства отображаются только включенные в настройках опроса каналы.

Также модуль отдаёт все данные по Modbus RTU (RS-485), которые можно читать любым оборудованием или ПО с поддержкой этого протокола: контроллерами сторонних производителей, HMI панелями или SCADA.

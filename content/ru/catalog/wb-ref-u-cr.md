#description

**Модель снята с производства. Рекомендуемая замена [WB-REF-U](https://wirenboard.com/product/WB-REF-U/)**

Сетевая карта для контроллера холодильного оборудования Carel, которая добавляет в него интерфейс RS-485 с поддержкой протокола Modbus RTU. Устройство подключается к контроллеру Carel через штатный разъём. Шлейф для подключения в комплекте.

WB-REF-U-CR можно использовать вместо оригинальной сетевой карты _IROPZ48505 (IROPZ48500)_ для подключения контроллера температуры Carel к контроллеру [Wiren Board](/product/wiren-board-6/).

Подходит к семействам контроллеров Carel BASIC и Carel EASY, неполный список моделей:

- PYEZ1R05J4
- PYEZ0ZB580
- PJEZC00100
- PJEZC0E000
- PJEZC0E120
- PJEZC0H000

- PJEZC0M100
- PJEZC0MG00
- PJEZC1E0I0K
- PJEZMNN0E0
- PJEZMNN0E0
- PJEZMNP000

- PJEZX00000

- PJEZY0M100

#description

**Модель снята с производства. Рекомендуемая замена: [WB-MAI2-mini / СС v.3](https://wirenboard.com/ru/product/WB-MAI2-mini-CC/).**

Двухканальный модуль аналоговых входов 0-20 мА. Устанавливается в распаечные коробки и кабельные каналы, подключается по Modbus RTU.

Применяется для подключения датчиков с выходом 0-20 и 4-20 мА в системах диспетчеризации инженерных систем и управления технологическими процессами.

## ОСНОВНЫЕ ХАРАКТЕРИСТИКИ

::product-section{title="Преимущества"}
:photo{
  src="wb-mai2-mini-cc-v1/wb-mai2-mini-cc-v1-2.png"
  width="500px"
  float="right"
}

- можно подключать датчики 0-20 мА и 4-20 мА;
- можно монтировать в распаечных коробках и кабель-каналах;
- фильтр для каналов с настраиваемым временем усреднения, позволяет отфильтровать резкие всплески тока, вызванные наводками;
- можно использовать с контроллерами других производителей;
- широкий диапазон напряжений питания (9…28 В);
- быстрая и простая интеграция в систему автоматизации и мониторинга;

- техническая поддержка на портале;
- русскоязычная документация;
- возможно нанесение логотипа вашей компании.
::

Технические характеристики:

- потребляемая мощность: 0.06 Вт;
- число каналов: 2;
- измерение тока: 0-20 мА;
- входное сопротивление: 49.9 Ом;
- погрешность при измерении тока: ±(0.1 мА + 1.5 %);

- напряжение питания: 9…28 В;
- температура эксплуатации: 0…+60 °С;
- интерфейс: RS-485, Modbus RTU;
- габаритные размеры: 57 x 18 x 12 мм.
::

При использовании с контроллером Wiren Board вы можете мышкой в веб-интерфейсе:

- включать и отключать опрос входов.

При использовании с другим оборудованием устройство можно настраивать по шине RS-485 через запись значений в Modbus-регистры. Таблица регистров открыта, хорошо документирована и доступна на нашем сайте.
::

Если используется контроллер Wiren Board, то измеренные значения доступны в веб-интерфейсе контроллера и могут быть использованы в сценариях автоматизации или переданы в систему верхнего уровня. В карточке устройства отображаются только включенные каналы.

Также модуль отдаёт все данные по Modbus RTU (RS-485), которые можно читать любым оборудованием или ПО с поддержкой этого протокола: контроллерами сторонних производителей, HMI панелями или SCADA.

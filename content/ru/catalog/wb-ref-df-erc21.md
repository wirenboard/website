#description

Сетевая карта для контроллера холодильного оборудования Danfoss, которая добавляет в него интерфейс RS-485 с поддержкой протокола Modbus RTU. Устройство подключается к контроллеру Danfoss через штатный TTL-разъём. Шлейф для подключения в комплекте.

WB-REF-DF-ERC21 можно использовать вместо оригинальной сетевой карты _Danfoss 191U0021_ для подключения контроллера температуры Danfoss к контроллеру [Wiren Board](https://wirenboard.com/ru/product/wiren-board-6/).

Подходит к моделям:

- ERC 211;
- ERC 213;
- ERC 214.

Если вы не нашли свою модель в списке — посмотрите [другие сетевые карты](/catalog/ref-modbus-adapters/) для холодильного оборудования. Возможно, ваш контроллер поддерживается одной из них.
